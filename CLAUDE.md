# Universal AI Lead Assistant

MVP AI-ассистента для входящих заявок малого бизнеса. Два режима:
**Receptionist** (чат с клиентом) и **Lead Processor** (разбор текста без ответа клиенту).
ТЗ: `Техническое задание (short).pdf`.

## Agent skills

### Issue tracker

Задачи ведём в GitHub Issues этого репо через `gh`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Пять стандартных меток: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. См. `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` и `docs/adr/` в корне. См. `docs/agents/domain.md`.
