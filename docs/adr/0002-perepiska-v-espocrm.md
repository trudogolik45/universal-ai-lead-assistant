# Переписка с Клиентом живёт в EspoCRM, а не в отдельном инбоксе

Сотрудник видит всю Беседу, включая ответы Ассистента, и отвечает Клиенту прямо в EspoCRM. Нужно одно место со всей историей Клиента. Своих Беседу и Сообщение делаем в EspoCRM сами: n8n кладёт входящие через REST API, экран обновляется через WebSocket. Ответ сотрудника уходит в Meta через свой PHP-хук afterSave, который вызывает n8n.

## Considered Options

- **Chatwoot** как общий инбокс. Отклонили: сотрудник работал бы в двух окнах, и история Клиента была бы разорвана.
- **Inbox в Meta Business Suite.** Отклонили: по отзывам, ответы бота в WhatsApp на Cloud API там не видны.
- **Messenger Center** (сторонний модуль для EspoCRM, около $750 в год). Отклонили: поддержка Cloud API и Instagram не подтверждена.
- **Встроенные webhooks EspoCRM** для ответа сотрудника. Отклонили: они уходят по расписанию, по умолчанию раз в 5 минут. Хук afterSave отправляет за секунды.
